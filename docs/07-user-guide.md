# Gestrin Hub 预览版使用指南

当前版本：0.1.0-preview.2（2026-10-19）。

## 语言与界面

在“设置 → 语言”选择“中文”或“English”，界面即时切换并保存选择，重启后保留。不会翻译用户游戏名、路径、标题 ID 或原始日志。Android 文件选择器和安装确认页仍使用系统语言；运行器自身语言由对应应用设置。

页面已移除宣传标语，保留功能标题和操作。运行器的版本限制、初始化方式收进“详情”，安装包摘要和真实性限制放在“校验信息”。游戏未实测的状态仍保留在详情中。

适用包名：`dev.gestrin.hub`。本页说明当前预览版操作及验证边界；构建、设备测试结果见 [验证与发布记录](08-verification-and-release.md)。

## 安装主应用

1. 获取同一发布来源提供的 Hub APK，核对发布记录中的版本、SHA-256 和签名身份。CI 的 `app-debug.apk` 是开发测试包，不能作为已完成签名与实机验收的正式版宣传。
2. 在 Android 手机上打开 APK，按系统提示允许本次安装来源并完成安装。主应用最低 Android 8.0 / API 26；运行器可能要求更高的 Android 版本及特定 CPU/GPU。
3. 打开 Gestrin Hub。主界面包含“游戏库”“运行器”“设置”，宽屏设备使用侧边导航。

APK 只包含 Hub 及其 Android 应用库；不捆绑模拟器、Windows 容器、游戏、固件、密钥或本地 AI 模型。联网下载由用户在应用内主动发起，首次打开应用不应自动安装运行器。

## 按需获取运行器

1. 打开“运行器”，找到需要的平台，点击“一键安装”。已安装版本可能显示“检查更新”，已下载的安装包可能显示“继续安装”。
2. Hub 从适配的上游来源获取安装包；等待进度完成。可以取消下载；下载失败时查看提示并重试，或使用“上游”查看来源。
3. Android 可能要求允许 Gestrin Hub“安装未知应用”。只在决定安装时开启，返回应用后使用“继续安装”；以实际系统提示为准。
4. 在 Android 安装确认页确认安装。“一键安装”表示应用内发起下载并交给系统安装器，仍需用户完成系统确认。
5. 打开运行器，完成其要求的首次配置。容器、固件、运行库、驱动等内部依赖按对应运行器指引由用户按需获取。Hub 不会替代其初始化步骤。

下载完成、安装器已打开、运行器主页已打开，均不能证明某款游戏可玩。Windows、XP3 的指定游戏交接仍需对应版本验证；PSP、Switch 的文件启动尝试同样以设备实测为准。PS Vita 需要先在 Vita3K 内安装游戏，再在 Hub 游戏详情中保存标题 ID（四个大写字母加五位数字）才能尝试标题启动；该入口也未完成本次设备实测。

## 建立游戏库

1. 在“游戏库”添加自己有权使用的本地游戏。单文件镜像选择“选择文件”；带相邻资源的 Windows / XP3 游戏优先选择完整目录。
2. 使用 Android 文件选择器授权文件或目录。系统提供方、可持久授权能力及外部运行器的读取权限可能不同。
3. 检查名称和平台；不明确的格式应由用户选择平台。不要把导入成功当成格式或兼容性验证。
4. 使用搜索、平台筛选、收藏及最近打开排序管理条目。打开详情可以编辑名称、平台、封面，并从仓库移除条目。移除条目应保留原始游戏文件。
5. 移动文件、撤销权限、切换文件提供方或恢复备份后，如果来源不可读，请重新选择原始文件或目录授权。

## 启动与问题记录

在游戏详情选择启动操作。部分平台只能打开运行器主页，之后需在运行器内选择或初始化游戏；“尝试启动游戏（待实测）”也不代表已验证支持。返回 Hub 后可记录“无法启动”“能启动”“可交互”，该记录只描述本次测试。

遇到问题时使用“检查启动条件”，也可以主动选择日志进行本地规则分析。建议只供排查参考，不会自动修改游戏或执行日志中的指令。当前没有通过设备基准的本地 AI 模型交付。

报告问题时记录 Hub 版本、设备/Android/GPU、运行器版本及来源、操作步骤和实际结果。日志及截图分享前检查个人目录、账号与游戏相关信息；外部运行器日志需要用户自行获取。

## 备份与恢复

在“设置”中使用“导出备份”，将备份保存到自己可访问的位置。当前 JSON 只导出游戏库元数据，不包含会话/测试记录、Vita 标题 ID 关联、游戏、运行器安装包或 Android 文件授权；不要将它当成完整历史备份。恢复后可能需要重新选择文件来源并重新关联 Vita 标题 ID；恢复前先保留现有备份。备份和日志应视作可能包含个人信息的文件。

## 当前验证边界

本指南不是设备兼容性承诺。安装确认、文件提供方授权、跨应用游戏交接、下载中断恢复，以及手机/平板和不同 GPU 的运行情况都需要真实设备记录。五类平台出现在界面中，不等于五类均已达到可玩里程碑。逐项状态以 [验证与发布记录](08-verification-and-release.md) 和 [接入探针](06-runner-probe-template.md) 为准。
