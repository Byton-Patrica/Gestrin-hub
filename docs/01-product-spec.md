# 产品规格 v0.1

## 范围

Gestrin Hub 统一管理用户已有游戏、关联运行器、启动入口、设备兼容性记录和诊断。五个首版平台为 Windows、XP3/KiriKiri、PSP、PS Vita、Switch，平等进入模型、筛选、适配器任务和验收表。XP3 采用同一套库与详情流程，不增加独立 Galgame 子系统。

Linux/SteamOS、PS2、Game Boy、安卓已安装游戏聚合、社交、商店、云同步后置。主应用不内嵌五套模拟核心；不承诺通用 EXE / XP3 / Switch 文件即点即玩。XP3 是资源归档，完整项目可能还需要脚本、插件和资源目录。

## 首版用户流程

1. 用户通过系统文件/目录选择器授权库位置；展示扫描候选、平台判断与置信度，允许修正。未知文件可保存为待配置条目。
2. 游戏库支持搜索、平台筛选、收藏、最近访问和用户封面。目录型游戏按完整项目归组，避免把每个补丁 XP3 当独立游戏；EXE 需确认主入口。
3. 详情页展示封面、平台、来源位置、关联运行器、最近会话、当前设备实测记录。未实测显示“未验证”，不可用文件后缀代替兼容性结论。
4. 首次启动展示运行器安装/初始化/授权步骤；安装来自经核实的上游链接并交给系统界面完成。用户在外部运行器创建 Windows 容器或安装 Vita 游戏，Hub 保存经验证的关联信息。
5. 有已验证直达能力时显示“启动游戏”；仅能打开外部主页时显示“打开运行器”，同时保留未完成接入状态。缺少前置条件时按钮解释阻塞原因。
6. 返回 Hub 仅表示回到前台，不自动认定游戏成功、崩溃或已退出。用户可记录结果或导入运行器导出的日志。
7. 诊断先给可解释规则结果，按需使用本地小模型解释已导入日志；建议列出依据、适用运行器版本和可撤销步骤。

## 视觉与交互

底部三入口：游戏库、运行器、设置；诊断从游戏详情进入。手机采用单列详情与自适应封面网格；平板宽窗口使用导航栏和库/详情双栏。按窗口宽度而非设备型号切换布局，支持横竖屏、分屏及状态恢复。

低饱和底色、少量强调色、统一圆角和文字层级；封面是主要视觉内容。正常动画建议 180–280ms，同一游戏封面可做共享过渡；支持系统减少动画，加载/权限错误不靠动画表达。触控目标至少 48dp，支持 TalkBack、200% 字体和明暗主题。性能目标见验收规范，均为目标而非已达成结果。

## 首版完成定义

五类均有至少一个明确 APK 版本、明确设备组合和合法样例完成指定游戏启动与 15 分钟可交互测试；至少有一次保存/重启后继续（样例不支持保存时记录原因和替代持久性检查）。每类都包含失败路径。暂时无可验证路径的类别保持阻塞，不能改成“支持”来满足名单。

五类全部有条目和安装引导可以交付早期预览，但不能宣称达到首版五类运行支持。性能和可玩性按具体组合披露，不能推广到整个平台游戏库。
