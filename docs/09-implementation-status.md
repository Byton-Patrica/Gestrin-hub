# v0.1 实施状态与新增要求

更新日期：2026-10-19。当前版本名 `0.1.0-preview.2`。这是可构建应用的预览，不代表原定五类完整运行验收已经完成。

## 应用包范围

新增要求已纳入：安装 APK 仅包括主应用及 Compose/Room 等应用自身所需库。兼容层、模拟核心、容器镜像、固件、密钥、游戏和模型不随 APK 提供。运行器中心的“一键安装”由用户主动发起：解析上游发行版 → 下载 → 校验 → 必要时请求安装来源授权 → 系统询问确认安装。拒绝授权后保留已下载文件，等待再次手动操作，不循环打开设置。

外部运行器中 Wine 环境、图形驱动等内部组件，交由用户在相应运行器内配置。Hub 不假定能将任意内部依赖写入其他应用私有目录。五类共用下载进度、取消、重试、检查更新、缓存清理和包校验信息入口。没有匹配 ABI/系统版本的官方 APK 或上游接口不可用时明确失败，不切换未知镜像。

## 已实现

- 精简界面标题与说明，移除标语，运行器说明按需展开。
- 应用内中文/英文切换，选择持久化；双语文案目录独立维护，动态消息保留原始路径与日志证据。
- 新原生矢量图标，自适应图标与 Android 13+ monochrome 图标；源文件 icon.svg。

- Kotlin + Compose 界面，深浅主题、减少动画、手机底栏、平板双栏。
- Room 游戏库和会话，SAF 文件/目录导入、项目聚合、去重、取消扫描、手动选平台。
- 搜索、收藏、排序、标题与平台编辑、本地封面、删除元数据。
- 五类运行器目录，已安装版本检测，用户主动下载与系统安装交接；上游可变 API 仍需设备回归。
- PSP、Switch 的 VIEW/content 文件交接尝试；Vita 已安装标题 ID 关联及显式启动尝试。
- Windows、XP3 当前提供运行器主页入口，未伪造指定游戏参数。
- 真实会话历史和用户观察结果；游戏库 JSON 备份/合并恢复。
- 用户日志导入、长度限制、脱敏与七类错误规则；不执行修复指令。

## 与原规划的差异

首个工程暂用单 app 模块和清晰包边界；偏好与 Vita 绑定使用 SharedPreferences，未引入 DataStore。备份只包含游戏元数据，不含会话、标题绑定、文件或 URI 授权。恢复后通过重新选择相同来源授权，重新设置标题绑定。

本地 AI 模型未接入；模型选型与设备基准未完成，界面明确标注当前为规则诊断。没有伪装成模型或自动修复。

Windows 和 XP3 的指定游戏启动仍受上游公开入口限制，五类实际游戏兼容性均待设备、游戏与运行器版本实测。M0/M2 的全部条件尚未满足，因此不能将本预览称为五类游戏已全部可玩。

最终构建、测试与产物校验结果见本次验证报告。构建通过不代替真机兼容性、下载/系统安装以及 15 分钟游戏交互测试。
