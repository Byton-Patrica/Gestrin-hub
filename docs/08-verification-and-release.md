## 下载与安装联调

运行器下载仅由用户主动点击触发。DownloadManager 保留进度并支持重启恢复；包下载后检查大小、ABI、SDK、包名、可读取签名、已安装应用的更新签名以及上游可取得的 SHA-256。没有上游哈希时明确显示未核验发布者哈希，不能把本地计算摘要当成独立真实性认证。

联调发现两类外部条件：模拟器需要使用本机已有代理才能访问网络；GitHub 公共 API 返回限流。已对模拟器配置独立代理，没有改动 Windows 代理；已实现读取实际官方网页发行链接的限流后备路径，PPSSPP 直接解析其官网标准 APK 链接，不构造猜测下载地址。真实网络与 APK 来源可能变化，必须保留版本/校验记录。

PPSSPP 1.20.4 已完成真实应用界面联调：官网解析 → 约 43 MB 下载（含网络超时后的系统重试）→ 安装包检查 → 安装来源授权 → Android 系统确认 → 安装完成。系统包管理器确认 org.ppsspp.ppsspp，versionName v1.20.4、versionCode 120040000；Hub 出现“打开”入口。实际测试了拒绝安装来源授权：返回 Hub 显示保留安装包的提示，没有循环打开设置。允许授权导致 Activity 重建时，需要再次点击“继续安装”，这与使用指南一致。

从 Hub 点击打开后，系统确认 PPSSPP 的 PpssppActivity 获得前台；随后使用 SwiftShader 的宿主模拟器显著卡顿，宿主模拟器进程内存升至约 15 GB，已停止本任务模拟器并重新启动。没有运行 PSP 游戏，不能把这个结果写成 PSP 游戏兼容或性能通过。Hub 的数据库/UI 测试在启动外部运行器之前完成。

首次 APK 发布者证书没有独立锁定；系统安装器负责最终签名校验。DownloadManager 的后续重定向及后台传输由系统管理，无法以此实现任意网络条件下的硬实时字节上限。所有运行器仍需完整的拒绝授权、取消、失败、升级、重启回归。
